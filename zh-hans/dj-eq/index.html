功能 / DJ EQ

一键切换 3 段 DJ 均衡器与 8 段均衡器。 同一首歌。在 iPhone 上

VibeDeck Player 在一个界面里有两个均衡器。3 段 DJ 均衡器像 DJ 调音台一样，用大推子调节 GAIN、BASS、MID 和 HIGH。8 段均衡器在 60、150、400 Hz 和 1、2、4、8、16 kHz 精细调整声音。点 3 BAND 或 8 BAND，音乐继续播放。

App 界面为英文：打开 EQ，点“3 BAND”或“8 BAND”。

DJ 用三个动作思考：低音、中音、高音。爱声音的人想要更细：16 kHz 多一点空气感，150 Hz 少一点闷。多数播放器只给其中一种。VibeDeck 两种都有，一键切换。

VibeDeck / 03

一键，两个均衡器

  • 01

    3 段 DJ 均衡器

    GAIN、BASS、MID、HIGH 大型竖推子，从 +12 到 -24 dB。不用看也能快速操作。

  • 02

    8 段均衡器

    60、150、400、1k、2k、4k、8k、16k 八个推子，各 -12 到 +12 dB，另有独立 GAIN。

  • 03

    VibeMod、限幅器、单声道

    VibeMod 是密实有力的声音处理。限幅器让大音量的峰值保持干净。单声道把混音合成一个声道，让制作人确认底鼓和贝斯是否在中间。

如何切换 3 段与 8 段

  1. 从 App Store 安装 VibeDeck Player。
  2. 播放曲库里的歌，打开 EQ。
  3. 点 3 BAND 使用 DJ 均衡器，推动 GAIN、BASS、MID 和 HIGH。
  4. 点 8 BAND 使用 8 段均衡器，从 60 Hz 到 16 kHz 调整每一段。
  5. 推得很响？打开 LIMITER。想要更密实有力的声音，打开 VIBEMOD。
  6. 点 MONO 用单声道听混音，点 RESET EQ 回到平直。

小提示

  • 随时切换： 在 3 段和 8 段之间切换时音乐不会停。
  • 两种风格： 3 段 DJ 均衡器适合快速大动作，8 段均衡器适合按耳机、音箱或车载音响细调。
  • 你自己的文件： MP3、FLAC、WAV 等格式，离线播放。
  • 在 iPhone 上： 3 BAND / 8 BAND 切换在 iPhone App 里。

适合谁

  • 制作人： 用单声道听自己的作品，确认底鼓和贝斯在中间、没有声音消失，以及混音在夜店音响和手机扬声器上的表现。再切回立体声对比。
  • DJ： 用 DJ 均衡器准备歌曲：drop 前去掉低音、拉高高音、用耳机检查混音。
  • 低音爱好者： 提高 60 Hz 加强 sub，控制 150 Hz。
  • 戴耳机： 按你的耳机调整 8 段。
  • 开车： 让声音适配车载扬声器。

FAQ / 06

VibeDeck DJ EQ：常见问题

VibeDeck 有 DJ 均衡器吗？

有。3 段 DJ 均衡器有 GAIN、BASS、MID、HIGH 推子，就像 DJ 调音台。

有 8 段均衡器吗？

有，在 iPhone 上：60 Hz、150 Hz、400 Hz、1 kHz、2 kHz、4 kHz、8 kHz、16 kHz，每段 -12 到 +12 dB，另有独立 GAIN。

怎么切换 3 段和 8 段？

打开 EQ，点面板上方的 3 BAND 或 8 BAND。音乐会继续播放。

可以用单声道听吗？

可以。点均衡器下方的 MONO。制作人用它确认底鼓和贝斯在混音中间。

VibeMod 是什么？

VibeMod 是一种特别的密实声音处理，让歌曲听起来更饱满有力。开关对比看看。

免费吗？
