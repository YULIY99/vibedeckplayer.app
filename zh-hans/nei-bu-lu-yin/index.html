功能 / 采样器

录下手机上正在播放的任何声音。 按下 Rec，播放，留下来

VibeDeck Sampler 直接从系统录下手机正在播放的声音。按下 Rec，切换到 YouTube、SoundCloud 或任何 App，录到想要的部分再回来就好。不用麦克风，没有环境噪音，也不需要电脑。支持 iPhone 和 Android。

App 界面是英文：请打开「Sampler」并按下「Rec」。

在视频、直播或 DJ set 里听到很棒的声音，却没有下载按钮。拿另一支手机靠近喇叭录，声音会很糟。Sampler 在播放的同时直接从手机录音，干净清楚。

VibeDeck / 03

听到、按 Rec、留下来

  • 01

    任何 App

    YouTube、SoundCloud、浏览器、游戏、语音频息。只要手机播得出来，Sampler 就录得下来。

  • 02

    干净的系统音频

    AAC 256 kbps、44.1 kHz，直接从手机录制。音量表会显示正在录进来的声音。

  • 03

    在波形上剪辑

    录音会变成波形。设置起点和终点，加上 0.5、1 或 2 秒的淡入淡出，先试听再保存。

如何录下手机的声音

  1. 从 App Store 或 Google Play 安装 VibeDeck Player。
  2. 打开 VibeDeck，进入 Sampler。
  3. 按下 Rec。
  4. 在 YouTube、SoundCloud 或其他 App 播放声音。
  5. 回到 VibeDeck 按下 Stop，录音会出现在 Recorded Samples。
  6. 点一下录音，就能在波形上剪辑。

录完可以做什么

  • Share：传到任何 App。
  • Save to Library：存成 All Tracks 里的一首曲目。
  • Open in Studio：做成循环，用音高、滤波、饱和与空间效果改造声音，录下你的版本并分享。

大家都录些什么

  • 视频里的一段：一段节拍、一句台词、一个音效。
  • 直播或 DJ set：想再听一次的段落。
  • 自己作品的素材：录下来，在 Studio 里改造，再发布成果。

FAQ / 06

VibeDeck Sampler 常见问题

怎么录手机的内部声音？

打开 VibeDeck Sampler，按下 Rec，再到任何 App 播放声音。VibeDeck 会在播放时录下系统音频。

可以录 YouTube 的声音吗？

可以。先在 VibeDeck 开始录音，再到 YouTube 播放视频，手机上播放的声音就会被录下来。

会用到麦克风吗？

不会。录的是系统音频，所以不会录进环境噪音。

录音品质如何？

AAC、256 kbps、44.1 kHz。

Android 可以用吗？

可以。Sampler 在 iPhone 和 Android 上的用法完全相同。

是免费的吗？
