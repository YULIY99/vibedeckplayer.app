效果 / Nightcore

手机上的 nightcore，一键完成。 更快、更高、更明亮

想做 nightcore，就在 VibeDeck Player 播放歌曲，打开 Effects，点 NIGHTCORE。歌曲会加快，音高也一起升高。调整速度、加入混响或低音，录下片段再分享。在 iPhone 和 iPad 上用你的 MP3、FLAC、WAV 离线使用。

App 界面为英文：打开 Effects，点“NIGHTCORE”。

Nightcore 和 slowed + reverb 相反：歌曲播得更快、更高，听起来更明亮、更有能量。速度和音高一起改变，就像唱片转得更快。在 VibeDeck 只要点一下 NIGHTCORE 预设，之后的声音由你自己调整。

如何在 iPhone 上做 nightcore

  1. 从 App Store 安装 VibeDeck Player 并导入歌曲。
  2. 播放歌曲并打开 Effects。
  3. 点 NIGHTCORE 预设。
  4. 想更快或更慢？拖动 SPEED / PITCH：速度和音高一起改变。
  5. 按喜好加入 REVERB 或 BASS BOOST。
  6. 要分享时，在 VibeDeck Studio 打开歌曲，按 REC，最长录两分钟。
  7. ORIGINAL 回到原来的声音。

其他一键预设

  • SLOWED + REVERB：更慢、更低，带长长的混响尾音。
  • DUB DELAY：跟着音乐节拍的回声。
  • VINYL DRIVE：像老唱片一样温暖饱满的声音。

FAQ / 06

Nightcore：常见问题

如何在 iPhone 上把歌曲做成 nightcore？

在 VibeDeck Player 播放歌曲，打开 Effects，点 NIGHTCORE。歌曲会加快、音高升高。也可以调整速度，加入混响或低音。

什么是 nightcore？

把歌曲播得更快、音高更高的版本，听起来更明亮、更有活力。

可以只加快速度、不升高音高吗？

可以。在 VibeDeck Studio 可以锁定调性，只改变速度。

可以录下并分享我的版本吗？

可以。在 Studio 按 REC，含淡入淡出最长录两分钟，然后分享片段。

可以离线使用吗？

可以。预设使用 VibeDeck 资料库里的音乐文件，不需要网络。
