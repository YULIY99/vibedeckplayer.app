功能 / BPM

每首歌的 BPM。 播放队列按速度排序

VibeDeck Player 直接在主界面显示正在播放歌曲的 BPM。播放队列可以按 BPM 排序：歌曲按速度范围分组，每首都标注精确 BPM。在 iPhone 和 iPad 上用你的 MP3、FLAC、WAV 离线使用。

App 界面为英文：速度显示为“BPM”。

DJ、跑者和舞者都想知道同一件事：这首歌的速度是多少？手动打拍子或另开 App 都很花时间。VibeDeck 显示资料库里每首歌的 BPM，并按速度排好，让下一首刚刚好。

如何知道歌曲的 BPM

  1. 从 App Store 安装 VibeDeck Player 并导入音乐。
  2. 播放歌曲，BPM 会出现在主界面。
  3. 打开播放队列，按 BPM 排序。歌曲按速度范围分组，并标注精确 BPM。
  4. 需要别的速度？在 VibeDeck Studio 打开歌曲并调整。key-lock 保持调性。

适合谁

  • DJ：把速度相近的歌放在一起，规划衔接。
  • 制作人：开工前确认参考曲的速度。
  • 跑步和健身：配合你节奏的播放队列。
  • 舞者：找到适合练习速度的歌。

FAQ / 05

BPM：常见问题

如何在 iPhone 上知道歌曲的 BPM？

把歌曲导入 VibeDeck Player 并播放，BPM 会显示在主界面。

可以按 BPM 排序音乐吗？

可以。播放队列按 BPM 排序后，歌曲按速度范围分组，每首都有精确 BPM。

可以改变歌曲的 BPM 吗？

可以。在 VibeDeck Studio 速度可从 -100% 调到 +100%，key-lock 保持调性。

可以离线使用吗？

可以。VibeDeck 使用设备上的音乐文件，不需要网络。
