อัปเดต / 1.0.21

มีอะไรใหม่ใน VibeDeck Player เวอร์ชัน 1.0.21

VibeDeck Player 1.0.21 มาพร้อม Stems: แยกเพลงไหนก็ได้เป็นอะคาเปลลาและดนตรี มิกซ์สด หรือเปิดใน Studio เพิ่มเอฟเฟกต์แล้วส่งออก VibeDeck ตอนนี้พอดีกับทุก iPad และทุก iPhone ทั้งรุ่นเก่าและใหม่ ปกที่หาเจอแสดงบนหน้าจอล็อกด้วย และค้นหาปกให้เพลงไหนก็ได้

แอปเป็นภาษาอังกฤษ: Stems อยู่ใน Library หมวด Tools

ทุกอัปเดตของ VibeDeck มาจากไอเดียเดียวกัน เพลงเดิม ความรู้สึกใหม่ เวอร์ชัน 1.0.21 เพิ่มเครื่องมือที่ใหญ่ที่สุดจนถึงตอนนี้ คือ Stems และทำให้แอปพอดีกับทุกหน้าจอ ตั้งแต่ iPhone เล็กที่สุดถึง iPad ใหญ่ที่สุด

เวอร์ชัน 1.0.21

  • Stems: แยกเพลงไหนก็ได้เป็นอะคาเปลลาและดนตรีบนมือถือ มิกซ์สดหรือเพิ่มเอฟเฟกต์ใน Studio แล้วส่งออก
  • iPad: VibeDeck พอดีกับทุก iPad และ iPhone ทั้งรุ่นเก่าและใหม่
  • ปกเพลง: ปกที่หาเจอแสดงบนหน้าจอล็อก ค้นหาปกให้เพลงไหนก็ได้
  • แก้ไขข้อบกพร่องและปรับปรุง

เวอร์ชัน 1.0.20

  • หลายเพลงพร้อมกัน: เลือกเพลงของคุณหลายเพลง แชร์ไปที่ VibeDeck แล้วจะอยู่ในคิว
  • เรียงตาม BPM: คิวจัดกลุ่มตามเทมโป แต่ละเพลงมี BPM ที่แม่นยำ
  • เลือกรูปคลื่น: Needles หรือ Bars
  • Stems ในคลัง: ใน Library หมวด Tools
  • แชร์จากคิว: ส่งเพลงที่เล่นอยู่จากเมนูของมัน
  • Hub สว่างขึ้น คิวและปุ่มหมุนใน Studio ลื่นขึ้น แก้ไขข้อบกพร่อง

ผู้ใช้ใหม่ทุกคนใช้ทุกฟีเจอร์ได้ 48 ชั่วโมง ไม่ต้องใช้บัตรและไม่ต้องสมัคร หลังจากนั้นเวอร์ชันฟรีเล่นเพลงได้ รวมถึงเล่นเบื้องหลัง อีควอไลเซอร์ ลิมิตเตอร์ และเครื่องมือเสียงอื่น ๆ ต้องใช้ VibeDeck PRO

อ่านเพิ่มเติม: วิธีแยกเสียงร้องออกจากเพลง nightcore บนมือถือ BPM ของทุกเพลง
