Fonction / BPM

Le BPM de chaque morceau. Et la file triée par tempo

VibeDeck Player affiche le BPM du titre en cours directement sur l’écran principal. Dans la file d’attente, vous pouvez trier par BPM : les titres sont regroupés par plage de tempo, avec le BPM exact sur chacun. Fonctionne hors ligne sur iPhone et iPad avec vos MP3, FLAC et WAV.

L’app est en anglais : le tempo s’affiche « BPM ».

DJ, coureurs et danseurs se posent la même question : quel est le tempo de ce morceau ? Taper le rythme ou ouvrir une autre app prend du temps. VibeDeck affiche le BPM de chaque titre de votre bibliothèque et les classe par tempo, pour que le suivant s’enchaîne bien.

Comment connaître le BPM d’un morceau

  1. Installez VibeDeck Player depuis l’App Store et importez votre musique.
  2. Lancez un titre. Le BPM apparaît sur l’écran principal.
  3. Ouvrez la file d’attente et triez par BPM. Les titres sont regroupés par plage de tempo, avec le BPM exact.
  4. Un autre tempo ? Ouvrez le titre dans VibeDeck Studio et changez-le. Key-lock garde la tonalité.

Pour qui

  • DJ : rapprocher des titres au tempo proche et préparer les transitions.
  • Producteurs : vérifier le tempo d’une référence avant de commencer.
  • Course et salle : une file à votre rythme.
  • Danseurs : des morceaux à la bonne vitesse pour répéter.

Chaque nouvel utilisateur a 48 heures avec tout débloqué, sans carte et sans inscription. Ensuite, la version gratuite lit la musique, aussi en arrière-plan. L’égaliseur, le limiteur et les autres outils de son nécessitent VibeDeck PRO.

FAQ / 05

BPM : questions fréquentes

Comment connaître le BPM d’une chanson sur iPhone ?

Importez la chanson dans VibeDeck Player et lancez-la. Le BPM s’affiche sur l’écran principal.

Puis-je trier ma musique par BPM ?

Oui. Triez la file par BPM : les titres sont regroupés par plage de tempo, avec le BPM exact de chacun.

Puis-je changer le BPM d’une chanson ?

Oui. Dans VibeDeck Studio, le tempo va de -100 % à +100 %. Key-lock garde la tonalité.

Cela fonctionne hors ligne ?

Oui. VibeDeck utilise les fichiers musicaux de votre appareil, sans internet.
