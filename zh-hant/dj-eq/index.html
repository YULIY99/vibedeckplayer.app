功能 / DJ EQ

一鍵切換 3 段 DJ 等化器與 8 段等化器。 同一首歌。在 iPhone 上

VibeDeck Player 在一個畫面裡有兩個等化器。3 段 DJ 等化器像 DJ 混音器一樣，用大推桿調整 GAIN、BASS、MID 和 HIGH。8 段等化器在 60、150、400 Hz 和 1、2、4、8、16 kHz 細緻調整聲音。點 3 BAND 或 8 BAND，音樂繼續播放。

App 介面為英文：打開 EQ，點「3 BAND」或「8 BAND」。

DJ 用三個動作思考：低音、中音、高音。愛聲音的人想要更細：16 kHz 多一點空氣感，150 Hz 少一點悶。多數播放器只給其中一種。VibeDeck 兩種都有，一鍵切換。

VibeDeck / 03

一鍵，兩個等化器

  • 01

    3 段 DJ 等化器

    GAIN、BASS、MID、HIGH 大型直推桿，從 +12 到 -24 dB。不用看也能快速操作。

  • 02

    8 段等化器

    60、150、400、1k、2k、4k、8k、16k 八個推桿，各 -12 到 +12 dB，另有獨立 GAIN。

  • 03

    VibeMod、限幅器、單聲道

    VibeMod 是密實有力的聲音處理。限幅器讓大音量的峰值保持乾淨。單聲道把混音合成一個聲道，讓製作人確認大鼓和貝斯是否在中間。

如何切換 3 段與 8 段

  1. 從 App Store 安裝 VibeDeck Player。
  2. 播放資料庫裡的歌，打開 EQ。
  3. 點 3 BAND 使用 DJ 等化器，推動 GAIN、BASS、MID 和 HIGH。
  4. 點 8 BAND 使用 8 段等化器，從 60 Hz 到 16 kHz 調整每一段。
  5. 推得很大聲？打開 LIMITER。想要更密實有力的聲音，打開 VIBEMOD。
  6. 點 MONO 用單聲道聽混音，點 RESET EQ 回到平直。

小提醒

  • 隨時切換： 在 3 段和 8 段之間切換時音樂不會停。
  • 兩種風格： 3 段 DJ 等化器適合快速大動作，8 段等化器適合依耳機、喇叭或車子細調。
  • 你自己的檔案： MP3、FLAC、WAV 等格式，離線播放。
  • 在 iPhone 上： 3 BAND / 8 BAND 切換在 iPhone App 裡。

適合誰

  • 製作人： 用單聲道聽自己的作品，確認大鼓和貝斯在中間、沒有聲音消失，以及混音在夜店音響和手機喇叭上的表現。再切回立體聲比較。
  • DJ： 用 DJ 等化器準備歌曲：drop 前拿掉低音、拉高高音、用耳機檢查混音。
  • 重低音愛好者： 提高 60 Hz 加強 sub，控制 150 Hz。
  • 戴耳機： 依你的耳機調整 8 段。
  • 開車： 讓聲音配合車上喇叭。

FAQ / 06

VibeDeck DJ EQ：常見問題

VibeDeck 有 DJ 等化器嗎？

有。3 段 DJ 等化器有 GAIN、BASS、MID、HIGH 推桿，就像 DJ 混音器。

有 8 段等化器嗎？

有，在 iPhone 上：60 Hz、150 Hz、400 Hz、1 kHz、2 kHz、4 kHz、8 kHz、16 kHz，每段 -12 到 +12 dB，另有獨立 GAIN。

怎麼切換 3 段和 8 段？

打開 EQ，點面板上方的 3 BAND 或 8 BAND。音樂會繼續播放。

可以用單聲道聽嗎？

可以。點等化器下方的 MONO。製作人用它確認大鼓和貝斯在混音中間。

VibeMod 是什麼？

VibeMod 是一種特別的密實聲音處理，讓歌曲聽起來更飽滿有力。開關比較看看。

免費嗎？

每位新使用者都有 48 小時可使用全部功能，不用信用卡也不用註冊。之後免費版可以播放音樂。等化器、限幅器和其他聲音工具需要 VibeDeck PRO。
