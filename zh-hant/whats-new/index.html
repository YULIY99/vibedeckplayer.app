更新 / 1.0.21

VibeDeck Player 新功能。 版本 1.0.21

VibeDeck Player 1.0.21 帶來 Stems：把任何歌曲分成清唱和伴奏，現場混音，或在 Studio 打開加入效果再匯出。VibeDeck 現在適合每台 iPad 和每支 iPhone，新舊都可以。找到的封面也會顯示在鎖定畫面，任何歌曲都能搜尋封面。

App 介面為英文：Stems 在 Library 的 Tools 裡。

VibeDeck 的每次更新都來自同一個想法：同一首歌，新的感受。1.0.21 加入目前最大的工具 Stems，並讓 App 適合每種螢幕，從最小的 iPhone 到最大的 iPad。

版本 1.0.21

  • Stems：在手機上把任何歌曲分成清唱和伴奏，現場混音或在 Studio 加效果後匯出。

版本 1.0.20

  • 一次分享多首：選一批自己的歌曲分享到 VibeDeck，它們就會在播放佇列裡。
  • 依 BPM 排序：播放佇列按速度分組，每首都有精確 BPM。
  • 選擇波形：Needles 或 Bars。
  • 資料庫裡的 Stems：在 Library 的 Tools 裡。
  • 從佇列分享：從選單直接傳送正在播放的歌曲。
  • 更亮的 Hub、更流暢的佇列和 Studio 旋鈕，以及錯誤修正。
